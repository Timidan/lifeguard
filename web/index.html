How a rescue runs

  1. The agent calls request_action with its function-call key, for example Repay 1,000 USDC.
  2. The contract builds the Base transaction itself, then NEAR's MPC network signs it with chain signatures.
  3. Anyone can broadcast the signed transaction. Aave on Base executes the repay.
  4. NEAR Read MPC proves the transaction succeeded on Base. Only then does the loan's nonce advance.

Testnet only: NEAR testnet and Base Sepolia, with Aave test tokens. No real funds.
